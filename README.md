# Lista de Exercícios de C#

Esta é uma atividade do Módulo 4 - Fundamentos de programação com C#. Dividi esse repositório em pastas, onde cada pasta é nomeada `ExercicioN` e pode ser testado individualmente. 

## Executando um exercício

Cada exercício pode ser executado individualmente a partir da raiz do projeto, utilizando o comando abaixo

```bash
dotnet run --project <ExercicioN>
```

### Exemplo

```bash
dotnet run --project Exercicio01
```
